# 🎨 Vaidilė Photography — Nauja versija

## Ką pakeitėme?
- **Tamsi kinematografinė estetika** (kaip Manus versijoje)
- **Švelnesnis tonas** — ne toks agresyvus juodas, minkštesnis auksinis
- **Lietuviškas turinys**
- **Playfair Display + Lato** šriftai

## Kaip įdiegti į savo projektą?

### 1 žingsnis: Atidaryti GitHub Desktop projektą
- Atidaryk **GitHub Desktop**
- Spausk **"Show in Finder"** — atsidarys `vaidile-photography` aplankas

### 2 žingsnis: Ištrinti VISUS senus failus
- Aplanke pažymėk visus failus (Cmd+A)
- Ištrink juos (bet NEIŠTRINK paties aplanko)
- **NEIŠTRINK** `.git` aplanko (jeigu jį matai — palik ramybėje)

### 3 žingsnis: Įkelti naujus failus
- Ištrauk (unzip) failą `vaidile-dark-gentle.zip`
- Iš gauto aplanko `vaidile-dark-gentle` **nukopijuok VISĄ turinį** (visus failus ir aplankus)
- Įklijuok į savo `vaidile-photography` aplanką

### 4 žingsnis: Push į GitHub
- Grįžk į **GitHub Desktop**
- Matysi visus pakeitimus
- Summary lauke įrašyk: `Dark cinematic redesign`
- Spausk **"Commit to main"**
- Spausk **"Push origin"**

### 5 žingsnis: Netlify automatiškai deploy'ins!
- Palauk 2-3 minutes
- Puslapis atsinaujins savaime 🎉
